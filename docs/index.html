PrintSplit

Split big models — armor, costumes, props — into parts that fit the 3D printers you own.

See it first: interactive demo — a life-size figure split for one Bambu Lab A1 and two Prusa MK4S, with each printer's build volume drawn around its part.
Use it in your browser (no install): open the repo in a GitHub Codespace; the app starts automatically.
Use it on your computer:
pip install git+https://github.com/OWNER/printsplit
printsplit
